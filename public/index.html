Cmder Container — Guide & Abbreviations

⚡ Keyboard Shortcuts & Abbreviations (Browser Friendly)

💡 Note: We use Alt + Key shortcuts so they never conflict with Chrome, Edge, or Windows browser tabs!

Shortcut Action Description
Ctrl + C Cancel / Copy Copies selected text cleanly, or sends SIGINT break to cancel command if no selection
Ctrl + V (or Right Click) Paste Text Pastes clipboard text directly into the active terminal once
Ctrl + Q, R, W, etc. Cmder Native All Ctrl keys (Ctrl+Q quit pager/branches, Ctrl+R history search, Ctrl+W erase word) pass directly to Cmder!
Alt + T New Tab Opens new isolated tab in the same folder as the current tab
Alt + S Scripts Store Opens Saved Scripts & Batch store to run/suggest custom routines
Alt + V Vault Store Opens Secrets & Notes Vault to paste passwords with 1-click
Alt + W Close Tab Safely closes active tab (Will not close Chrome window)
Alt + ← / → Move Between Tabs Navigate left / right between tabs using arrow keys
Alt + 1 .. 9 Jump to Tab Instantly switches directly to Tab #1 through Tab #9
Alt + B Broadcast Toggles the broadcast bar to run a command across all tabs
Alt + G Grid View Toggles between single full-screen tab and multi-tab grid view
Alt + H / F1 Help Guide Opens / closes this guide window
Double Click Rename Tab Double-click any tab title to name it (e.g. Frontend, DB)

📜 Custom Batch & Scripts Store (run_c)

You can save server logins, credentials, SSH commands, or dev scripts in the app:

  • In Terminal: Type run_c to list all saved scripts. Type run_c <name> to execute!
  • In UI: Click Scripts in the header or press Alt + S to search, get suggestions, and run with 1-click.

📁 Managing Multiple Project Folders

Click the 📁 button in the top bar to open a tab directly in any folder on your PC. Pressing Alt + T or clicking + automatically opens new tabs in the same folder as your current tab.

⚡ Broadcast Mode (Inter-Tab Connection)

Press Alt + B to open the broadcast bar. Type any command (such as git pull, npm test, or dir) and press Enter to execute it across all your open tabs simultaneously!

💾 Automatic Tab Caching (Session Memory)

Your open tabs, folder paths, and custom names are automatically saved in real-time. Whenever you close and reopen the app, all your tabs reload right where you left off.
