Cmder Container — Guide & Abbreviations

⚡ Keyboard Shortcuts & Abbreviations (Browser Friendly)

💡 Note: We use Alt + Key shortcuts so they never conflict with Chrome, Edge, or Windows browser tabs!

Shortcut Action Description
Ctrl + C (or Auto-Select) Copy Text Select text with mouse to auto-copy, or press Ctrl+C
Ctrl + V (or Right Click) Paste Text Pastes clipboard text directly into the active terminal
Alt + T (or Ctrl+T) New Tab Opens a new isolated Cmder tab (No conflict with Chrome!)
Alt + W (or Ctrl+W) Close Tab Safely closes active tab (Will not close Chrome window)
Alt + ← / → Move Between Tabs Navigate left / right between tabs using arrow keys
Ctrl + Tab Cycle Tabs Quickly cycle through tabs forward / backward
Alt + 1 .. 9 Jump to Tab Instantly switches directly to Tab #1 through Tab #9
Alt + B Broadcast Toggles the broadcast bar to run a command across all tabs
Alt + G Grid View Toggles between single full-screen tab and multi-tab grid view
Alt + H / F1 Help Guide Opens / closes this guide window
Double Click Rename Tab Double-click any tab title to name it (e.g. Frontend, DB)

📁 Managing Multiple Project Folders

Click the 📁 button in the top bar to open a tab directly in any folder on your PC. Each tab maintains its own independent working directory, so you can work on 10+ projects side-by-side without losing your paths.

⚡ Broadcast Mode (Inter-Tab Connection)

Press Ctrl + B to open the broadcast bar. Type any command (such as git pull, npm test, or dir) and press Enter to execute it across all your open tabs simultaneously!

💾 Automatic Tab Caching (Session Memory)

Your open tabs, folder paths, and custom names are automatically saved in real-time. Whenever you close and reopen the app, all your tabs reload right where you left off.
